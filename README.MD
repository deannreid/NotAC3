## 👋 Meet Not A C³

Not A C³ is a self-hosted command-and-control and security orchestration
platform built for red teams, purple teams, detection engineers, researchers,
and anyone experimenting responsibly inside a controlled lab.

It brings payload creation, agent communications, tasking, collection,
reconnaissance, relay infrastructure, and multi-operator workflows together in
one extensible platform—with a web console that does not look like it escaped
from 2009.

The name **C³** stands for:

- **Command** — operational tasking and execution
- **Control** — orchestration, scheduling, and collaboration
- **Conker** — the lightweight endpoint agent

But this is, of course, **Not A C³**.

Obviously.

## ✨ One Platform, Plenty of Mischief

| | Capability | What it brings |
|---|---|---|
| 🛰️ | **Cross-platform agents** | C, Python, PowerShell, Go, and Rust templates for Windows, Linux, and macOS |

| 📦 | **Collection workflows** | Files, screenshots, credentials, keylogs, loot, timelines, and searchable operational data |
| 🗺️ | **Operation management** | Campaigns, target scope, scenarios, approvals, ATT&CK mapping, reporting, and audit history |
| 🔌 | **Integrations** | Versioned APIs, webhooks, notifications, plugins, and pluggable relay providers |
| 👥 | **Team controls** | Role-based access, operator preferences, sessions, approvals, and accountable activity |

## 🚀 More Than a Beacon and a Task Queue

Not A C³ is designed as a platform rather than a collection of disconnected
scripts. Agents, transports, communication profiles, relays, plugins, and
operator modules can evolve independently while sharing the same control
plane.

That means you can use the pieces you need, extend the ones you care about,
and avoid rebuilding an entire interface every time a new experiment gets out
of hand.

```text
Operators and Integrations
           │
           ▼
   Not A C³ Control Plane
   ├── Agents and tasking
   ├── Payloads and profiles
   ├── Listeners and relays
   ├── Recon and collection
   └── Operations and audit
           │
           ▼
     Conkers and Relays
```

## 🚧 Project Status

Not A C³ is under active development on the **4.0 release line**.

The core platform is functional and growing quickly. Some areas remain
experimental, interfaces may change, and new modules regularly appear with
the confidence of code that has never met production before.

Current development is focused on:

- Broader cross-platform agent coverage
- More reusable malleable communication profiles
- Additional relay and infrastructure providers
- A richer plugin and API-module ecosystem
- Improved collaboration, reporting, and operational visibility
- Safer testing, packaging, and deployment workflows

More details coming soon™.
